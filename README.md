# Benefits and Costs of Earthquake Early Warning, two studies presentation

A Persian, right-to-left interactive web presentation reviewing the benefits, costs, and broader value of earthquake early warning (EEW) systems.

**Live presentation:** [mohammadmolaeinia.github.io/hypothesis-presentation-1](https://mohammadmolaeinia.github.io/hypothesis-presentation-1/)

## Overview

This single-page presentation introduces the operation and potential value of EEW systems, drawing on two studies published in 2016. It was prepared for presentation to the author's thesis supervisor as part of an MSc earthquake-engineering project.

## Academic context and purpose

The presentation supports literature review and discussion related to the author's MSc thesis in earthquake engineering at the International Institute of Earthquake Engineering and Seismology (IIEES). It is a presentation and literature review prepared for thesis supervision—not the thesis itself—and it does not claim original research results.

## Scientific scope

Topics covered include:

- EEW definition and workflow, including P-wave detection, signal processing, and prediction and warning before S-wave shaking;
- Examples of EEW systems worldwide, potential beneficiaries, applications, and public access;
- Operating costs, estimated benefits, broader social value, and benefits for infrastructure and industry;
- Organizations and selection criteria considered in the second study, with an illustrative cost-benefit chart.

## Features

- Interactive slide navigation and agenda;
- Slide transitions, modal dialogs, and keyboard and click interactions;
- Responsive layout and Persian right-to-left typography;
- Illustrative cost-benefit chart.

## Technology stack

Built with semantic HTML5, CSS3, and vanilla JavaScript. No framework, dependencies, or build step are required.

## Local usage

Clone the repository and open `index.html` in a web browser:

```bash
git clone https://github.com/mohammadmolaeinia/hypothesis-presentation-1.git
cd hypothesis-presentation-1
```

Alternatively, serve the project locally with Python:

```bash
python -m http.server 8000
```

Then visit <http://localhost:8000>.
